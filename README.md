# Discord-Bot
Projeto de desenvolvimento de um Bot para Discord utilizando Python, explorando programação assíncrona, criação de comandos e integração com APIs.

Discord Bot

Bot para Discord desenvolvido em Python utilizando a biblioteca Discord.py.

O projeto tem como objetivo explorar o desenvolvimento de bots, criação de comandos personalizados, programação assíncrona e integração com a API do Discord.

Status: Em desenvolvimento 🚧

Tecnologias utilizadas

* Python
* Discord.py
* Git e GitHub

Funcionalidades

* Comando de saudação
* Novos comandos personalizados
* Sistema de interação com usuários
* Novas funcionalidades em desenvolvimento

Instalação

1. Clone o repositório:

git clone URL_DO_REPOSITORIO

2. Entre na pasta:

cd discord-bot

3. Crie e ative um ambiente virtual:

python3 -m venv .venv
source .venv/bin/activate

4. Instale as dependências:

pip install -r requirements.txt

5. Configure o arquivo .env com seu token:

DISCORD_TOKEN=seu_token_aqui

6. Execute o bot:

python main.py
